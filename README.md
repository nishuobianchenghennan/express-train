# 讲明白

“讲明白”是一款本地优先的个人综合表达训练系统。它从经过设计的场景任务卡中约束抽题，引导用户亲自完成检索、来源判断、观点整理、第一次表达、自评和针对性重讲；系统给路径，不提供主题答案、完整提纲或可照读稿件。

## 已实现

- 365 张固定、版本化、结构化任务卡，覆盖 10 类表达场景与 12 个内容领域
- 确定性的 365 天年度路径：每天一张、每张恰好一次，并按难度递进、避免相邻场景/领域/结构重复；闰年跳过 2 月 29 日
- 指定场景、弱项强化和题库手动启动仍使用自适应选题，兼顾近期覆盖、短期去重和难度匹配
- 研究表达、临场表达、互动沟通、正式任务四类训练协议
- 敏感互动任务完全自愿，可不说明原因立即反复跳过，且不占用普通一次换题额度
- 可恢复的分阶段计时、暂停与延长、来源记录、动态整理模板和分层帮助
- 浏览器本地录音、回听、分项自评、唯一目标与即时重讲
- 历史多条件筛选、7/30 天覆盖、指标趋势与重复问题识别
- IndexedDB 本地数据、JSON 导入导出、版本一致的离线缓存与 PWA 安装

## 要求

- Node.js 20.11 或更新版本
- Bun 1.3 或更新版本
- 录音需要支持 `MediaRecorder` 的现代浏览器；麦克风权限仅在点击录音后请求

## 启动

```bash
bun install
bun run dev
```

默认开发地址为 `http://127.0.0.1:3000`。开发服务器提供 `public/`。

生产启动需先生成 `dist/`：

```bash
bun run build
bun run start:prod
```

`STATIC_DIR` 仅允许指向项目目录内、真实存在且包含 `index.html` 的静态目录；配置到项目外部、缺少目录或缺少入口文件都会在启动时失败。

## 命令

```bash
bun run dev        # 启动并监听服务端文件变化
bun run start      # 启动开发静态服务器
bun run start:prod # 以 NODE_ENV=production 启动并提供 dist/
bun run lint       # 检查 JavaScript 语法、JSON 与尾随空格
bun run test       # 运行 Node.js 测试
bun run build      # 校验离线缓存清单并生成 dist/
bun run check      # 依次运行全部检查、测试与构建
```

## 隐私与数据

训练记录、笔记、收藏和录音默认保存在当前浏览器的 IndexedDB 中；应用不接入广告或行为分析。JSON 导出不包含录音文件。静态服务器仍可能处理提供页面所需的 IP、User-Agent 等基础访问信息，具体取决于部署环境。

## 内容边界

题卡只提供训练任务、检索问题、来源要求、空白整理模板、结构和评价标准。医疗、法律、投资等高风险内容要求可靠来源与明确边界，但应用不提供个体诊断、法律意见或投资建议。

# 讲明白

> 本地优先的表达训练系统：从“不知道怎么开口”练到“能说会道”，训练终点是**创业者**——能带团队、见投资人、对外把一件事讲清楚。

路线贴着一位真实处境的学习者设计：**博士在读 → 走向产业 → 创业者**，日常生活与社交贯穿全程。训练分两件事：

1. **学一课**：30 课，每课学一种表达结构，配经典框架、逐句拆解的示范和反例，最后换到另一条线的场景里迁移。
2. **练一回合**：从学过的结构里抽一道真实场合的题，限时开口、中途被打断、回听自查；讲完之后才揭晓本题的最优方案，再带着追问重讲。

首页只有一个入口“今日训练”。所有训练数据只保存在你自己的浏览器里。

## 成长路线：四条线

```
学术线（博士在读）──→ 转化线（从实验室走向产业）──→ 创业线（创业者）
└──────────── 生活社交线：贯穿全程 ────────────┘
```

| 线 | 覆盖的场合 |
| --- | --- |
| 学术线 `academic` | 博士在读：组会、导师、答辩、学术会议 |
| 生活社交线 `life` | 贯穿全程：闲聊、倾听、致辞、圆桌与沙龙 |
| 转化线 `bridge` | 从实验室走向产业：访谈、合作、大赛、合伙人 |
| 创业线 `founder` | 创业者：路演、融资、招人、客户、团队与媒体 |

四条线的出题比例**不用手选**。AI 整理画像时，按你的身份和接下来要面对的场合，从下面三档里判断一档；没有 AI 整理画像时用默认的第一档。画像页会显示当前比例。

| 判断依据 | 学术 | 生活社交 | 转化 | 创业 |
| --- | --- | --- | --- | --- |
| 在读学生或科研人员（默认） | 50% | 25% | 15% | 10% |
| 正从学业或科研走向产业、求职或创业 | 25% | 20% | 35% | 20% |
| 已经工作或在创业 | 5% | 20% | 20% | 55% |

某条线暂时没有可出的题（例如对应的结构还没学）时，它的权重按比例分给其余线。

题卡里的学习者是一条贯穿始终的**虚构**人物线：陈明，博一，研究风电齿轮箱在变工况下的故障诊断；转化线里拿着技术去访谈、找合伙人；创业线里是做电池健康管理（储能电站为主要客户）的创始人。人物、数字、机构均为模拟，用来让四条线的题目前后连贯，不对应真实的人或公司。

## 30 课

每课教一种表达范式，五个阶段按“敢开口 → 讲清楚 → 能交锋 → 能推动 → 创业者”递进。学完一课，它的结构就进入练习题池。

“经典框架”一列写作 `名称 · 出处`。出处写作**常见用法**的，表示这个框架广泛流传、但找不到单一的权威出处，因此不标具体作者；第 9、20 课没有公认的经典框架，结构为本项目自建。

## 语境地图：56 类真实场合

每类语境描述一个真实场合：你的身份、对方是谁、对方此刻在想什么、冲突点，以及在这里可用的结构、需要额外检查的关键行为和专属的打断/追问。

**学术线（15）**：组会进展汇报、组会报告坏消息、和导师谈研究方向分歧、向导师争取资源、拒绝额外杂活、和导师谈毕业节奏与发表计划、开题/中期/答辩陈述、答辩被评委质疑、学术会议报告与提问、海报前的 60 秒、向外行讲清研究、当助教讲清一个方法、跨课题组发起与推进合作、奖学金/项目申报答辩、课堂/讨论课被点名。

**生活社交线（11）**：新环境自我介绍、饭局闲聊与被问看法、茶歇/晚宴上和前辈搭话、倾听和安慰情绪低落的人、拒绝朋友或社团的请求、家人追问读博与人生安排、同门或室友冲突的协调、即兴致辞与祝酒、读书会/沙龙上的观点交锋、圆桌讨论中接话与补充、主持一场沙龙或活动。

**转化线（10）**：用户访谈：问需求而不推销、向从业者请教一个陌生行业、和企业谈横向合作、创业大赛路演与评委答辩、和导师谈创业打算、说服潜在合伙人、拜访校友前辈开口求助、专利转让与作价入股沟通、向非技术人员介绍技术方案、实习/访学/求职面试。

**创业线（20）**：投资人电梯介绍、天使轮正式路演、路演问答被尖锐质疑、融资条款与估值谈判、说服大厂工程师加入、招聘面试候选人、向客户介绍并演示产品、客户议价、全员会讲愿景与目标、全员会宣布坏消息、合伙人方向分歧、给团队成员批评反馈、客户投诉与危机回应、媒体采访与播客、行业论坛圆桌嘉宾、政府/园区项目申报答辩、向董事会汇报经营进展、跨团队推进一件事、拒绝客户的不合理要求、两分钟行业速评与趋势判断。

当前共 **113 张题卡**：学术线 30、生活社交线 22、转化线 20、创业线 41。每类语境至少 2 张，每课至少 2 张。每张题卡都绑定一课的结构，并附带本题专属的选结构引导、最优方案、反例和补课问题。创业线和部分转化线题卡关联 18 个行业画像之一，补课时会显示该行业的关键指标与术语。

## 训练流程

### 今日计划（首页）

首页最上面是一张“下一步”行动卡，系统按优先级只给一个主按钮，另一件事作为次要按钮：

1. **继续**：有进行中的回合或课时，先继续它。进度实时保存在本地。
2. **到期复练**：3–30 天前完成、首轮有没做到的项、还没复练过的回合，直接开始，并换一组打断和追问。
3. **学一课**：一课都没学时是“开始第 1 课”；之后当天还没学课时推荐下一课，下一课的 AI 示范已写好时会注明。次要按钮是“先练一回合”。
4. 其余时候（今天学过课，或 30 课都学过）不单独出行动卡，下面的**练一回合**就是主操作，标题旁给“学下一课 / 复习某一课”的入口。

往下依次是 AI 通知条（新题、待确认的观察）、**练一回合**（抽题轮盘约 5 秒定格，一律是完整回合，抽中后可以“换一题”），以及一行**进度**：已学结构（x / 30）、今日回合、近 7 天、连续天数和当前弱项。四条线覆盖与接住打断率在能力档案里看。

另有“30 课”页（按五个阶段浏览、自选任意一课，页头有“开始下一课”的主按钮）、训练历史、能力档案和设置。

### 学一课：6 步

| 步骤 | 你要做什么 | 页面上有什么 |
| --- | --- | --- |
| **1 看懂场景** | 读示范场景，理解难点和对方心理 | 场景难点、对方此刻在想什么、结构及每一步的作用和句式、经典框架与本课结构的对应关系 |
| **2 拆解示范** | 读出声，逐句理解为什么有效 | 按步骤着色的逐句示范、一段糟糕说法和它的问题 |
| **3 模仿复述** | 示范收起，用自己的话复述 | 完整提示（步骤名 + 句式）、录音和用时；讲完逐步自查 |
| **4 优化再讲** | 针对漏掉的步骤再讲一遍 | 提示减少到只剩步骤名，上次漏掉的步骤标红 |
| **5 换语境迁移** | 同一个结构，换到**另一条线**的真实题目 | 没有示范，只有步骤名和迁移提示；自查时还要判断该语境的关键行为 |
| **6 完成** | 写一句带走的话 | 三次表达的步骤覆盖对比；可以“用这个结构练一回合”、学下一课或回首页 |

**固定的是表达框架，不是场景**。结构、步骤、句式和经典框架每次都一样；示范场景（情境、你的身份、对象、难点、对方心态、示范回答和反例）在开启 AI 后按你的画像生成：后台提前为推荐的下一课写好示范，开课时有就用，没有就用课内自带的精选示范，不让你等。AI 写的示范标有“AI 按你的画像生成”。

迁移题优先选与示范不同线、且从没用作本课迁移题的题卡；都用过时选最久没用的。

### 练一回合

```
读题 → 准备（选结构引导）→ 开口（中段被打断）→ 回听检查
     → 补课（揭晓本题最优方案）→ 揭晓追问 → 重讲 → 复盘
```

| 阶段 | 你要做什么 | 系统做什么 |
| --- | --- | --- |
| **读题** | 看情境、身份、对象和目标 | 显示所属的线与语境、选题原因 |
| **准备** | **不写稿**，按引导想清楚往哪说 | **选结构引导**：先回答场景判断三问（对方是谁 / 他此刻最想听什么 / 我要他听完做什么）→ 推荐结构及理由 → 每一步往哪个方向说。**只给方向，不给答案**。语境还适合其他结构时，以一行提示列出，但检查清单只按推荐结构出 |
| **开口** | 限时表达 | 录音计时；讲到中段弹出一条打断并播放提示音；到时提示收尾，10 秒宽限后自动结束 |
| **回听检查** | 完整回听，逐项判断“做到 / 没做到”，再选**唯一**的重讲目标 | 自动建议目标（先选没做到的结构步骤；全部做到时选“接住打断”），可以改选 |
| **补课** | 对照结构，找出差在哪 | **揭晓本题最优方案**：逐句标出属于哪一步、为什么这样说，你首轮漏掉的步骤对应的句子高亮；一段反例；补课问题；关联行业时显示关键指标与术语。5 分钟软性计时 |
| **追问 + 重讲** | 先回应追问，再重讲，只改一项 | 揭晓一条与打断不同的追问，20 秒准备后计时录音 |
| **复盘** | 再判断一次清单，写一句带走的话 | 首次 → 重讲逐项对比；有没做到的项时安排 3 天后复练 |

每个回合都是完整回合（约 10 分钟，包含补课）。早期版本的“闪电回合”已取消，历史里的闪电回合记录照常显示。

最优方案标注为**本题的一种好答案，不是唯一答案**，对照的是结构，不是逐字。

**中断恢复**：录音中途刷新或关闭页面时，会回到当前阶段，可以重新开讲；录音进行中离开页面会先弹出确认。

## 选题规则

抽题只在**已学结构**的题卡中进行，按以下顺序执行。“软过滤”指过滤后为空就跳过这一步、保留原候选，所以软过滤不会把候选清空。

1. **候选池**：结构属于已学课的全部题卡；为空则不出题，首页只推荐课。
2. **到期复练**：有到期复练且题卡仍在候选池中时，以 50% 概率直接返回它，并避开上次用过的打断和追问。
3. **去重**（硬过滤，逐级放宽）：排除最近 30 个回合练过的题卡 → 仍为空则只排除最近 10 个 → 仍为空则不排除。
4. **选线**：在仍有候选的线之间按画像决定的出题比例加权随机，之后只在选中的线内继续。
5. **交错**（软过滤）：排除与上一回合相同语境或相同结构的题卡。
6. **难度**（软过滤）：完成 0–5 个回合时目标难度为 1，6–17 个为 2，18 个以上为 3；有弱项时上限放宽一级。
7. **弱项**（软过滤）：有当前弱项时，以 60% 概率只保留考核该弱项的题卡。
8. **加权抽取**：基础权重 1；所属课在最近 3 天内刚学完的 ×1.5。

选题原因由实际生效的步骤拼出，例如“学术线 · 强化弱项「结论先行」 · 刚学的范式”。

## 可观察检查清单

每个回合的清单由三部分组成，只判断“做到 / 没做到”，拿不准就算没做到：

1. **结构步骤**：推荐结构的每一步“讲出来了吗”。
2. **语境关键行为**：该语境最关键的几项行为，来自下面 20 项。
3. **接住打断**：每个回合都有打断，所以总是检查。

| 检查项 | 回听时判断的具体问题 |
| --- | --- |
| 结论先行 | 开口 15 秒内，对方已经知道你的结论、请求或立场 |
| 一条主线 | 全程围绕一条主线，没有临时岔开或越讲越散 |
| 具体可感 | 至少出现一个具体事实、数字、例子或画面 |
| 事实与推测分开 | 已确认的事实、你的判断和未知信息是分开说的 |
| 对方听得懂 | 用的是对方关心、听得懂的话，没有堆术语 |
| 下一步明确 | 结尾有明确的下一步：谁、做什么、什么时候 |
| 接住打断 | 被打断或追问时，先正面回应，再回到主线 |
| 按时收住 | 在规定时间内主动收尾，没有被时间截断 |
| 稳住节奏 | 卡壳、口头禅没有打断理解（回放中明显卡顿不超过 3 次） |
| 先接情绪 | 先确认了对方的处境或情绪，再讲方案 |
| 讲出代价 | 说出了代价、风险或取舍，而不是只讲好处 |
| 承担责任 | 说清了自己的责任和动作，没有甩锅或泛泛而谈 |
| 从对方出发 | 从对方的目标或收益讲起，而不只讲自己的需要 |
| 把话轮交回 | 抛出一个具体问题，推动对方回应 |
| 故事有细节 | 讲的是一个具体瞬间：时间、场景和你的动作，而不是概括 |
| 层次可辨 | 听众能听出你讲了几点、正讲到第几点 |
| 不急于辩解 | 面对质疑先承认合理部分，没有急着反驳 |
| 有自己的判断 | 给出了明确的个人判断，而不是只罗列各方观点 |
| 给出替代 | 说“不”的同时，给出了一个可行的替代方案 |
| 不乱承诺 | 没有当场承诺自己控制不了的事 |

每一项都附带一句“下次怎么改”的具体说法，例如结论先行：“第一句话就给结论：‘结论是……，原因有两点。’”。

**弱项**只统计最近 20 个完成回合的**首轮**（冷启动）结果，分两类：

- **行为弱项**：按上表各项统计做到率（含接住打断）。观察至少 3 次、做到率低于 70% 的项中最低的一项。
- **结构弱项**：按课统计步骤覆盖率（首轮讲出的步骤数 / 总步骤数）。至少 3 个回合、覆盖率低于 70% 的课中最低的一课。结构步骤只在同一课内比较，不跨课合并。

两类都有时取更低的一个，相等时取行为弱项。**能力档案**页列出各检查项的首轮与重讲做到率、各课的步骤覆盖率、接住打断率和四条线的覆盖情况。

## 压力事件：打断与追问

共 34 条压力事件。每类语境有自己的打断池和追问池：打断在首次表达的中段弹出；追问在重讲前揭晓，重讲必须先回应它。同一回合里打断和追问不重复，复练时会避开上次用过的。部分示例：

| 类型 | 示例 |
| --- | --- |
| 通用 | “说重点，你需要我做什么？”；“这个数字哪来的？你确定吗？”；对方没有回应，只是看着你，等你继续 |
| 学术 | 评委打断：“这和已有的工作到底有什么区别？”；“你的样本量够支撑这个结论吗？”；“这个问题已经超出你的研究范围了吧？” |
| 生活社交 | 家人叹了口气：“读这么久，到底图什么？”；“你们读博一个月补助多少？”；对方低声说：“我真的觉得自己不适合干这个。” |
| 圆桌与媒体 | 另一位嘉宾抢过话头：“我插一句，我完全不同意。”；记者追问：“所以你是承认你们的产品有问题？”；主持人提醒：“还剩最后一分钟。” |
| 创业 | “如果大厂明天也做这个，你怎么办？”；“为什么是现在？早几年、晚几年不行吗？”；“你博士还没毕业，能全职投入吗？”；“这个估值我们没法接受。” |

## 旧数据

本版本把旧版的三套内容（学习模式 19 课、342 张“行业 × 场景”实战卡、365 张主题题库任务卡）收拢为“30 课 + 56 类语境 + 题卡”一套体系。旧数据的处理方式：

- **只读保留**：旧版实战回合、旧版课程、旧版主题题库训练记录在训练历史中标注“旧版训练”只读显示；能力页底部折叠区保留旧版统计口径。它们**不参与**新版的弱项、复练、选题、连续天数和“已学结构”。
- **进行中的旧训练**：升级后首次加载时标记为放弃并归档到历史，提示一次“旧版训练已归档”。
- **新旧区分**：一律看记录的 `schemaVersion`（新为 2，旧为 1），旧记录按冻结在 `public/js/legacy/` 中的旧题库校验。
- **导出 v2**：导出格式升为 `version: 2`，不再包含进行中的主题训练和收藏。
- **导入兼容 v1**：同时接受 v1 和 v2。v1 中的记录分流为旧版；进行中的旧主题训练归档为放弃；`favorites` 字段接受并忽略；已废弃的 `homeTrack` 设置接受任意值并丢弃。
- 收藏、年度计划、题库页已随主题训练一并移除。IndexedDB 仓库结构不变，不需要升级数据库。

## AI 助手（可选）

不配置也能完整使用；配置后，课程示范和练习题都按你的画像持续生成，不再只有固定的精选内容。固定的是 30 课的表达框架，场景随人而变。设计与依据见 [`docs/superpowers/specs/2026-10-21-ai-agent-design.md`](docs/superpowers/specs/2026-10-21-ai-agent-design.md)。

**它做五件事**

1. **画像调研**：问卷（一句话身份、想提高的方面、接下来要面对的真实场合、五项自评、题目深浅、练习计划），可选让 AI 追问 2–3 个细节，再由 AI 整理成画像摘要，把真实场合对应到 56 类语境，并判断四条线的出题比例（不再手选阶段）。
2. **我的画像（记忆）**：查看、编辑、逐条删除“记住的事”；显示当前出题比例；自评与实测（练习中首轮做到率）并排对比；可以预览“将发送给模型的内容”（画像摘要和训练摘要）。
3. **课程示范**：后台为推荐的下一课预先生成示范。结构和步骤不变，情境、身份、对象、难点、对方心态、示范回答和反例都按画像来写；人物不再默认是博士生。示范场合会避开本课的迁移语境，并且和迁移题分在不同的线。生成失败或还没生成好时，用课内自带的精选示范。
4. **按画像和训练进度出题**：只为已学的结构出题，题库里保持 2 道没练过的新题（有当前弱项时，是 2 道考核该弱项的新题；没练过的新题最多攒 5 道）。
   - 每次出题都附上现算的**训练摘要**：30 课学到哪一课、当前难度目标、本题结构各步的首轮讲出率、行为弱项、最近练过的题和最近写下的“带走的一句话”。
   - 本结构首轮讲出率低于 70% 的步骤（至少练过 2 次，最多 2 步）作为“重点考查的步骤”，要求情境让这一步非讲不可。
   - 规划时最近 3 天学完的课权重提高 1.5 倍；难度不超过当前目标（有弱项时可高一级）；没练过的新题抽中概率是普通题的 3 倍，它针对的弱项已经不是当前弱项时降到 1.5 倍。
   - 生成的题卡与精选题卡同一结构、通过同一套校验，场合名、身份、对象、难点也按画像改写（例如“组会进展汇报”对职场人显示为“周会进展汇报”），然后进入抽题、复练、弱项统计和课程迁移。开始一课时，迁移步骤会尽量换成按你的真实场合生成的题。
5. **练习观察**：每完成 5 个回合，AI 读最近 10 个回合的记录（题目、没做到的检查项、重讲改的那一项、带走的话），提出最多 3 条带依据的观察，放进画像页的“待确认的新观察”。你点“记住”才写入“记住的事”，点“忽略”就丢掉，之后也不会再提（删掉从练习采纳的记忆同理）；模型不会直接改写画像。

**训练流程不变**：AI 只写情境与答案，练什么（语境、结构、难度、弱项）仍由代码决定；生成失败时照常使用精选题卡。

**配置**

1. 安装依赖：`bun install`（新增 `@anthropic-ai/sdk`），启动 `bun run dev`。
2. 填写模型服务，两种方式任选：
   - **网页填写（推荐）**：在运行服务的这台电脑上，用 `http://localhost:3000` 或 `http://127.0.0.1:3000` 打开“设置 → AI 助手 → 填写模型服务”，填密钥、接口地址和模型，保存后立即生效，不用重启。
   - **`.env`**：复制 `.env.example` 为 `.env`，按下表填写，然后重启服务。
3. 打开“我的画像”完成调研，勾选“允许把画像和训练摘要发送给模型服务”。

**网页填写的规则**

- 保存在项目根目录的 `ai-config.local.json`（已加入 `.gitignore`；可用环境变量 `AI_CONFIG_FILE` 改路径），不存进浏览器。密钥保存后页面只显示“已配置”，不会再回显。
- 网页填写的每一项优先于 `.env`；清空某一项就回到 `.env` 的值。
- 只接受本机直接访问：连接必须来自本机、地址栏是 `localhost` / `127.0.0.1`、且没有经过反向代理。局域网里的其他设备、代理后面的访问都不能改配置。
- 更换接口地址时必须同时填写这个地址的密钥；网页填写的地址也不能沿用 `.env` 里另一个地址的密钥。这样已保存的密钥不会被发到一个新地址。

| 变量 | 说明 |
| --- | --- |
| `AI_DEFAULT_PROVIDER` | `anthropic` 或 `openai`；不填时用第一个配置好的 |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | Claude（官方 SDK，默认 `claude-opus-5-5`）。Anthropic 官方 API 不支持中国大陆访问 |
| `OPENAI_COMPAT_BASE_URL` / `OPENAI_COMPAT_API_KEY` / `OPENAI_COMPAT_MODEL` | OpenAI 兼容接口：通义千问、DeepSeek、智谱、豆包等。模型名建议写带日期的固定版本 |
| `OPENAI_COMPAT_LABEL` | 设置页显示的名称，如“通义千问” |
| `OPENAI_COMPAT_JSON_MODE` | `json_schema`（默认，严格结构化输出）或 `json_object`（DeepSeek、智谱等只支持 JSON 模式的服务） |
| `OPENAI_COMPAT_EXTRA_BODY` | 附加到请求体的 JSON，如通义千问严格结构化输出需要的 `{"enable_thinking": false}` |
| `AI_CONFIG_FILE` | 网页填写的配置保存在哪个文件，默认项目根目录的 `ai-config.local.json` |
| `AI_ACCESS_CODE` | 访问码。设了之后，AI 请求必须带同样的访问码（在设置页填一次，保存在这台设备的浏览器里）。本机运行可以不设；部署到 Cloudflare Pages 时必须设，否则线上 AI 不开放 |

两家都配置时，可以在设置页切换。密钥只在本机服务端使用：`GET /api/ai/status` 只返回服务名、模型名和是否已配置；设置页表单读取的 `GET /api/ai/config` 只说明密钥是否已配置、来自网页还是 `.env`，不返回密钥。

**不要把密钥写进 `.env.example`**：这个文件会提交到 git，密钥只写在 `.env`（不提交）或网页里。

**隐私**：AI 默认关闭，勾选同意后才开启，可随时在设置页关闭。发送的内容：

- 调研时：问卷回答（含五项自评）和追问回答。
- 出题和生成课程示范时：画像摘要、训练摘要（两者都可在画像页预览）和出题规格。
- 提炼观察时：画像摘要、训练摘要、已有记忆、你忽略或删除过的观察（让模型不再提出），以及最近 10 个回合的题目、没做到的检查项和带走的话。

录音从不发送。早期版本只发送画像摘要；升级后发送范围扩大，之前同意过的用户会看到“发送内容有更新”，AI 暂停，重新勾选后才继续。

## 快速开始

**要求**

- Node.js 20.11 或更新版本
- Bun 1.3 或更新版本
- 支持 `MediaRecorder` 的现代浏览器（Chrome、Edge、Firefox、Safari 新版）

```bash
bun install
bun run dev
```

打开 `http://127.0.0.1:3000`。首次进入会显示一页简短说明，可以先做画像调研，也可以跳过直接从第 1 课开始。

麦克风权限会在第一次开口时请求。拒绝后可以选择“只计时，不录音”，但回听检查只能凭记忆，准确度会下降。

**生产部署**

```bash
bun run build      # 校验课程体系与离线缓存清单并生成 dist/
bun run start:prod # 以 NODE_ENV=production 提供 dist/
```

`public/_headers` 为静态托管平台提供与开发服务器一致的安全响应头。

**部署到 Cloudflare Pages（GitHub 自动部署）**

静态托管只提供页面，AI 接口由仓库里的 `functions/api/ai/[[path]].js`（Pages Function）提供，推送后随页面一起部署。

1. 在 Cloudflare 控制台打开这个 Pages 项目 → Settings → Variables and Secrets，按上面的变量表添加模型服务（例如 `OPENAI_COMPAT_BASE_URL`、`OPENAI_COMPAT_API_KEY`、`OPENAI_COMPAT_MODEL`、`OPENAI_COMPAT_JSON_MODE`），**再添加访问码 `AI_ACCESS_CODE`**。密钥和访问码选 Encrypt。正式环境（Production）和预览环境（Preview）分别设置。
2. 重新部署（改变量后要重新部署才生效）。部署记录里应能看到 Functions。
3. 打开线上网站 → 设置 → AI 助手，填一次访问码。之后这台设备就能用 AI；换设备要重新填。

线上不能在网页里填写模型服务（Pages 没有可写的文件），模型服务只在 Cloudflare 控制台设置。没设 `AI_ACCESS_CODE` 时线上 AI 一律不开放，避免别人打开网站就用掉你的模型额度。

## Android App

`mobile/` 用 Capacitor 8 把 `public/` 原样打包成 Android 应用（侧载安装，不上架）。网页代码只通过 `public/js/platform.js` 区分平台：App 里接管系统返回键、键盘、系统栏和启动页，导出改走系统分享，不注册 Service Worker；网页里行为不变。Capacitor 的依赖只装在 `mobile/`，不影响根目录和 Cloudflare 构建。

**要求**：Android Studio 2025.2.1 或更新版本（自带 JDK 21）、Android SDK 36、Node.js 22 或更新版本、Bun；手机为 Android 7.0 及以上（华为 HarmonyOS NEXT 不能直接安装 APK）。

```bash
cd mobile
bun install
bun run sync     # 复制 ../public 到 www/，打包原生桥，同步到 android/
bun run android  # 装到 USB 连接（已开 USB 调试）的手机或模拟器
bun run open     # 用 Android Studio 打开，可在 Build → Build APK(s) 打出安装包
```

改了 `public/` 之后重新 `bun run sync` 再安装。命令行打包时需要 `JAVA_HOME` 指向 Android Studio 的 `jbr`、`ANDROID_HOME` 指向 SDK，然后在 `mobile/android` 下运行 `gradlew assembleDebug`，安装包在 `app/build/outputs/apk/debug/`。

- **数据**：App 的数据和浏览器里的数据是分开的。第一次使用时在网页版设置页导出 JSON，再到 App 设置页导入。卸载 App 会清空数据；用同一个签名覆盖安装会保留。默认用本机的调试签名，换电脑打包后无法覆盖安装，换之前先导出数据。
- **AI**：App 里在设置 → AI 助手填写服务地址（部署好的 `https://项目.pages.dev` 或自定义域名）和访问码。Pages Function 只对 App 的来源 `https://localhost` 开放跨域，改过 `functions/` 后要重新部署一次。`pages.dev` 在国内网络下可能连不上，此时 AI 显示未连接，离线训练不受影响。
- **录音**：第一次开口时系统会请求麦克风权限。

## 技术实现要点

- **零前端依赖**：浏览器原生 ES Module 加字符串模板渲染，没有框架，也没有打包步骤。服务端依赖 `express`、`dotenv`，以及 AI 助手用的 `@anthropic-ai/sdk`（首次调用时才加载，未安装时只有 AI 不可用）。
- **严格 CSP**：`style-src 'self'` 禁止内联样式属性，所有动态位移和宽度都通过 CSSOM 或 Web Animations API 写入。例如首页轮盘用 `element.animate()` 驱动，能力页的进度条用 `element.style.width` 写入。
- **内容即数据，加载时校验**：30 课、56 类语境和题卡都是冻结的纯数据。`validate.js` 检查引用是否存在、最优方案是否按顺序覆盖每一步、语速是否超限、题量是否达标、每课是否有不同线的迁移题卡；`index.js` 在加载时做结构校验，测试和 `bun run build` 中做完整校验（内容没写全时构建失败）。
- **状态机**：练习回合（`engine.js`）和课程（`lesson-engine.js`）都是纯函数，`random` 与 `now` 可注入，阶段顺序、校验、推进、选题、统计都可以单独测试。界面层只负责渲染和计时。
- **计时不触发整页重渲染**：计时器每 200ms 直接更新时钟、进度条、打断提示和超时提示的 DOM 节点。阶段开始时间持久化，刷新后可以恢复倒计时。
- **录音健壮性**（`recorder.js`，回合与课程共用）：
  - 等待麦克风授权期间进入“请求中”状态，可以随时改为只计时；
  - 授权迟到时自动释放麦克风；
  - 录音保存失败时按只计时处理，不中断训练。
- **存储**：
  - IndexedDB v2，包含 `kv`、`sessions`（旧版主题训练，只读）、`drills`（练习回合）、`recordings` 四个仓库；课程记录和当前课程保存在 `kv` 中。IndexedDB 不可用时退回到 localStorage。
  - 回合归档与当前进度在同一事务里写入。
  - 按 `schemaVersion` 分流校验：新记录要求题卡、语境、课和检查项都存在于新题库；旧记录按 `legacy/` 校验。导入时拒绝未知题卡、未知检查项和重复记录。
- **离线与 PWA**：`sw.js` 预缓存完整模块图。`bun run build` 会校验 `app.js` 引用的每个本地模块都在缓存清单里，缺一个就构建失败。

## 测试

```bash
bun run test
```

当前共 91 项测试，覆盖：

- **课程内容**：30 课按阶段 7/7/7/6/3 齐全且课序正确；56 类语境按线 15/11/10/20 齐全；四条线题卡数量与设计一致；检查项 20 项、压力事件保留全部旧 ID；完整模式内容校验通过；校验器能发现引用错误、步骤覆盖错误、语速超限和缺少跨线迁移题卡。
- **课程**：课程记录以课为键；一课完整走完时的检查清单；迁移选卡优先不同线、未用过；已学课只统计新版完成记录；推荐下一课与“刚学”判定。
- **练习回合**：先开口后补课，闪电回合跳过补课；准备阶段只给选结构引导、补课阶段才揭晓最优方案；清单 = 步骤 + 关键行为 + 接住打断；重讲目标建议。
- **选题**：没学任何课时不出题；三档出题比例下 5000 次抽题的线占比与权重表偏差不超过 5 个百分点；无候选的线权重转给其他线；去重逐级放宽；交错；难度与弱项软过滤；到期复练换压力；刚学的课加权；软过滤不会清空候选。
- **统计**：行为弱项与结构弱项分开统计、步骤不跨课合并；旧回合不参与；连续天数、线覆盖、接住打断率、到期复练。
- **存储与旧数据**：`careerStage` 设置与 `homeTrack` 丢弃；新旧回合和课程按 `schemaVersion` 分流；导入 v1 / v2；旧版进行中训练归档；事务原子性；旧版统计口径保持不变。
- **服务端与外壳**：安全响应头、SPA 回退、`/health`、配置校验、离线缓存模块图完整、抽题动画不依赖内联样式。

## 隐私与数据

- 课程记录、练习回合、补课笔记和录音默认只保存在当前浏览器的 IndexedDB 中，不上传，也不接入广告或行为分析服务。
- 可以在“设置”中导出或导入 JSON。导出包含课程记录、练习回合、旧版训练记录、画像和 AI 生成的题卡，但**不包含录音文件**；同一设备上再导入时，会保留本机已有的录音。
- AI 助手默认关闭。开启后，画像摘要、训练摘要与出题规格经本机服务端发送给你选择的模型服务；提炼练习观察时还会发送最近回合的题目、没做到的检查项和带走的话。录音不发送。详见 [AI 助手（可选）](#ai-助手可选)。
- “设置 → 清除本地数据”会删除全部数据库和本地缓存。
- 静态服务器仍可能处理提供页面所需的 IP、User-Agent 等基础访问信息，具体取决于部署环境。

## 内容边界与局限

- **最优方案是一种好答案，不是唯一答案**。学的是结构和每一步的作用，不是逐字背诵；对照时看结构，不看措辞。
- **示范与题卡中的人名、数字、机构均为模拟**。学习者陈明及其研究方向、公司、客户、融资经历是一条虚构的连贯线索，不对应真实的人或公司；题卡里不写具体的真实统计数据。
- 经典框架的出处只标注能核对到的作者或机构；标为“常见用法”的框架没有单一权威出处。框架用来帮助理解结构，不代表原作者对本项目内容的认可。
- 行业画像只包含长期稳定的定性信息（岗位、常用指标名、典型矛盾），**不写具体数据**。行业事实需要你在补课阶段自行检索核实。
- 涉及医疗、金融、法律的场景只训练沟通方式，应用不提供诊断、法律意见或投资建议。
- 回听判断仍由你本人完成，无法替代真人听众或教练的反馈。条件允许时，把录音给同事或朋友听，用同一份清单让他们判断。
- 打断和追问是文字提示，不是真人对话，模拟不了对方的语气和临场反应。
- 精选题卡每类语境约 2 张，不开 AI 时练多了会重复；四条线权重和难度划分是起步设定，尚未经过使用数据校准。
- AI 生成的题卡通过了结构校验（步骤覆盖、语速、字段完整），但情境是否合理、最优方案是否真的好，校验器判断不了；遇到不合理的题，可以换一题。
- 每天练几个回合最合适，目前没有直接针对口头表达训练的研究；建议的节奏只是起步参考。

## 研究依据

| 设计 | 证据 | 可信度 |
| --- | --- | --- |
| 新手先学示范（学一课） | 示范例题效应元分析 g = 0.48（[Educational Psychology Review 2023](https://eric.ed.gov/?id=EJ1364058)，数学领域）；对新手有效的示范，对有经验者效果下降甚至变负，即专长逆转效应（[Kalyuga 等 2003](https://mrbartonmaths.com/resourcesnew/8.%20Research/Explicit%20Instruction/The%20Expertise%20Reversal%20Effect.pdf)） | 高（证据主要来自数学和理科，用到表达上是推论） |
| 提示逐步撤掉、最后迁移 | 从完整示范逐步过渡到独立完成，能提升近迁移表现（[Atkinson, Renkl & Merrill 2003](https://www.researchgate.net/publication/200772684_Transitioning_From_Studying_Examples_to_Solving_Problems_Effects_of_Self-Explanation_Prompts_and_Fading_Worked-Out_Steps)） | 中高 |
| 好坏示范对比 | 先分析对比案例再接受讲解，迁移表现更好（[Schwartz & Bransford 1998](http://aaalab.stanford.edu/assets/papers/earlier/A_time_for_telling.pdf)） | 中 |
| 先观察示范再练习 | 口头表达训练中，观察示范与练习结合时进步最大（[De Grez, Valcke & Roozen 2014](https://eric.ed.gov/?id=EJ1024484)）；观看示范视频能提升学生的演讲表现（[Okada 等 2017](https://www.researchgate.net/publication/322265508_R211_Okada_Sawaumi_Ito_T_2017_Effects_of_observing_model_video_presentations_on_Japanese_EFL_learners'_Oral_performance_Electronic_Journal_of_Foreign_Language_Teaching_14_129-144)） | 中 |
| 练习回合先开口、后揭晓最优方案 | 先尝试后学习优于先学后练：[Sinha & Kapur 2021](https://www.researchgate.net/publication/351889202_From_problem-solving_to_sensemaking_A_comparative_meta-analysis_of_preparatory_approaches_for_future_learning) 元分析，53 项研究，g = 0.36；[Richland, Kornell & Kao 2009](https://learninglab.uchicago.edu/Pre-Testing_files/RichlandKornellKao.pdf) 的预测试效应。前提是学习者已有一定基础，所以只从已学的结构里出题 | 高 |
| 二元可观察清单、从严判断 | 口头表达的自评普遍高于教师评分，相关约 r = 0.46（[De Grez 等 2012](https://eric.ed.gov/?id=EJ972240) 及同类研究）；要求使用结构化量表的录像自评，第二次表现更好（[Ritchie 2016](https://journals.sagepub.com/doi/10.1177/1469787416654807)） | 高 |
| 反馈聚焦任务行为、每次只改一项 | 反馈干预平均 d = 0.41，但超过三分之一反而降低表现；注意力越离开任务、越指向自我，效果越差（[Kluger & DeNisi 1996](https://www.mrbartonmaths.com/resourcesnew/8.%20Research/Marking%20and%20Feedback/The%20effects%20of%20feedback%20interventions.pdf)） | 高 |
| 中途打断与追问 | 带着焦虑练习的人，在压力下表现不下降（[Oudejans & Pijpers 2009](https://research.vu.nl/en/publications/training-with-anxiety-has-a-positive-effect-on-expert-perceptual--2/)）；压力接种训练元分析，压力下表现 r = 0.30（[Saunders 等 1996](https://www.researchgate.net/publication/13725612_The_effect_of_stress_inoculation_training_on_anxiety_and_performance)）。证据主要来自运动和职业领域，用到口头表达上是推论 | 中 |
| 间隔复练 | 间隔练习优于集中练习（[Cepeda 等 2006](https://augmentingcognition.com/assets/Cepeda2006.pdf)，839 项评估） | 高 |
| 语境与结构交错 | 交错练习元分析 g = 0.42，效果随材料差异很大（[Brunmair & Richter 2019](https://www.psychologie.uni-wuerzburg.de/fileadmin/06020400/2019/Brunmair_Richter_in_press__2019_META-ANALYSIS_OF_INTERLEAVED_LEARNING.pdf)） | 中 |
| 给外行讲清研究（第 8 课等） | 自我解释 g = 0.55（[Bisra 等 2018](https://gwern.net/doc/psychology/spaced-repetition/2018-bisra.pdf)）；为教而学 g ≈ 0.35–0.56（[Kobayashi 2019](https://onlinelibrary.wiley.com/doi/10.1111/jpr.12221)） | 中高 |
| 不迷信练习时长 | 刻意练习只解释约 12%–14% 的表现差异，在职业领域低于 1%（[Macnamara 等 2014](https://gwern.net/doc/psychology/2014-macnamara.pdf)）。所以本项目更看重**练习质量**：真实场合、压力、具体反馈，而不是累计时长 | 高 |
| 经典框架 | 各课所用框架及出处见 [30 课](#30-课) 表；标为“常见用法”的没有单一权威出处 | — |

# 讲明白

> 本地优先的表达训练系统，分两步：**学习模式**先拆解示范回答、模仿复述、换行业迁移，学会每个场景的表达结构；**实践模式**再抽一个真实场景，限时开口、中途被打断、回听自查、带着追问重讲。

“讲明白”想同时练三件事：

1. **表达**：在限时、有压力的条件下把话说清楚。
2. **跨行业认知**：了解 18 个行业的岗位、关键指标和行业变量。
3. **临场应变**：被打断、被质疑、被追问时接得住。

学习模式提供示范回答和逐句拆解，用来学会结构；实践模式只提供场景、压力事件和检查标准，**不提供答案**。所有训练数据只保存在你自己的浏览器里。

## 为什么这样设计

常见的表达练习方式有五个问题，本项目逐一针对：

| 常见做法 | 问题 | 本项目的做法 |
| --- | --- | --- |
| 直接让新手上场讲 | 新手不知道“好的表达”长什么样，练再多也只是在重复自己的习惯 | **学习模式先给示范**：逐句拆解好回答为什么好，再对比一段糟糕说法，然后模仿、逐步撤掉提示、换行业迁移 |
| 先查资料、写提纲，再开口 | 准备时间远多于开口时间；真实场合也不会给你准备的时间 | **实践模式先开口，后补课**：准备只有 5–30 秒，讲完再针对讲不出来的地方限时补课 |
| 讲完给自己打 1–5 分 | 自评普遍高估，分数无法指导改进 | **二元可观察清单**：只判断“做到 / 没做到”，拿不准就算没做到 |
| 一个人从头讲到尾，没有干扰 | 练不到应变，压力一来就乱 | **中途打断 + 重讲前追问**：在压力下练，才能在压力下用 |
| 议论文式题目（“XX 是必需品吗？”） | 和工作、社交中的真实表达场景脱节 | **行业 × 真实场景**：汇报、谈判、投诉、面试、被点名等高频场合 |

每一项设计对应的研究证据见文末[研究依据](#研究依据)。

## 两种模式

首页顶部可以随时切换模式，系统会记住你的选择。第一次使用默认进入学习模式。

| | 学习模式 | 实践模式 |
| --- | --- | --- |
| 适合谁 | 表达新手，或者第一次接触某类场景 | 已经学过这类场景的结构，想检验能否在压力下用出来 |
| 有没有示范 | 有，并且逐句拆解 | 没有，只有场景和检查标准 |
| 提示 | 逐步撤掉：完整句式 → 只剩步骤名 → 换行业 | 回听时可以展开对照推荐结构 |
| 压力 | 没有打断，时间只是建议 | 中途打断、重讲前追问、到时自动收尾 |
| 一次多久 | 约 12 分钟一课 | 完整回合约 10 分钟，闪电回合约 4 分钟 |

**两种模式是连在一起的**：学完一课后可以一键进入实践模式，练同一类场景，但换成第三个行业、不给提示、会被打断。学过的场景在实践模式的自适应选题里会优先出现（约 70%）。

## 学习模式：先模仿，再迁移

19 课，每类场景一课，按难度从 L1 到 L3 排列。系统会推荐下一课，也可以自选。一课分 6 步：

| 步骤 | 你要做什么 | 页面上有什么 |
| --- | --- | --- |
| **1 看懂场景** | 读示范场景，理解难点和对方的心理 | “这个场景难在哪”“对方此刻在想什么”、表达结构名称、为什么用这个结构，以及每一步的作用和可迁移句式 |
| **2 拆解示范** | 读出声，逐句理解每一句为什么有效 | 完整示范回答、按步骤着色的逐句拆解（每句标出属于哪一步、为什么这样说）、一段常见的糟糕说法和它的问题 |
| **3 模仿复述** | 点“我理解了”后示范收起，用自己的话复述 | **完整提示**：步骤名 + 句式；录音和用时 |
| **自查** | 回听，逐步判断“这一步我讲出来了吗” | 可以展开对照示范；判断完会列出漏掉的步骤，以及可以怎么补 |
| **4 优化再讲** | 针对漏掉的步骤再讲一遍 | **提示减少**：只剩步骤名，上次漏掉的步骤标红；自查时显示上一次的结果 |
| **5 换行业迁移** | 同一个结构，换一个行业的同类场景 | **没有示范**，只有步骤名和迁移提示；自查时除了结构步骤，还要判断这个场景的关键行为 |
| **6 完成** | 写一句带走的话 | 三次表达的步骤覆盖对比；可以去实践模式、学下一课或回首页 |

每课的内容包括：
- **场景难点和对方心理**：例如坏消息汇报中，“总经理最怕两件事：意外，以及被下属把坏消息包装过”。
- **表达结构**：4–5 步，每步写明作用和可迁移句式。例如坏消息汇报是“坏消息—已知与未知—已做动作—需要的决定”。
- **示范回答**：对着示范场景写成，按步骤逐句标注“为什么这样说”。语速控制在每秒 4.6 字以内，能在建议时长内讲完。
- **反例对比**：一段新手常见的说法，指出 3–4 个具体问题。
- **迁移提示**：换到别的行业时，哪些部分保留、哪些部分替换。

同一课再学一次时，迁移题会换一个没练过的行业。示范里的人名、数字和经历都是模拟的，用来展示结构，不代表真实行业数据。“面试行为题”一课的示范用的是大学社团经历，请换成你自己的真实经历。

## 实践模式：一个实战回合怎么进行

```
读题 → 准备（5–30 秒）→ 开口（30–120 秒，中段被打断）→ 回听检查
     → 限时补课（5 分钟，仅完整回合）→ 揭晓追问 → 重讲 → 复盘
```

| 阶段 | 你要做什么 | 系统做什么 |
| --- | --- | --- |
| **读题** | 看情境、对象和目标 | 显示选题原因（弱项强化 / 新行业 / 间隔复练） |
| **准备** | 只想两件事：第一句话说什么、用哪个具体例子。**不写稿** | 倒计时，结束后自动开始录音；也可以提前开讲 |
| **开口** | 限时表达 | 录音计时；讲到 40%–60% 时弹出一条打断并播放提示音；到时提示收尾，10 秒宽限后自动结束 |
| **回听检查** | 完整回听，逐项判断“做到 / 没做到”，再选**唯一**的重讲目标 | 判断完后自动建议一项没做到的作为目标，可以改选；可以展开对照这类场景的推荐结构 |
| **补课** | 针对刚才讲不出来的地方，每个问题只写关键词 | 给出行业认知问题和检索关键词（优先年报、招股书等一手资料），5 分钟软性计时 |
| **追问 + 重讲** | 开场先回应追问，再重讲，只改一项 | 揭晓一条与打断不同的追问，然后计时录音 |
| **复盘** | 再判断一次清单，写一句“带走的话” | 显示首次 → 重讲的逐项对比；有没做到的项时，安排 3 天后复练 |

**两种回合**

- **完整回合**（约 10 分钟）：包含补课，适合每天第一回合。
- **闪电回合**（约 4 分钟）：跳过补课，只有开口 → 回听 → 追问重讲，适合多练几次。

**中断恢复**：进度实时保存在本地。录音中途刷新或关闭页面时，会回到当前阶段，可以重新开讲。录音进行中离开页面会先弹出确认。

## 题库：19 类场景 × 18 个行业

共 **342 张实战卡**，每张都是“某个行业里的某个真实场景”。例如：

> **会上被质疑 × 银行与金融服务**
> 你是一家城市商业银行的支行对公客户经理。周会上你刚说完「不良率」有改善，风险管理部的负责人当众说：“这个改善是你们做的，还是本来就会自然波动？”所有人都看着你。
> 目标：承认质疑中合理的部分，拿出能分辨原因的证据，并提出验证方法。

### 场景（按 6 类场景家族）

括号内依次是难度、准备时间、开口时限。

| 家族 | 场景 |
| --- | --- |
| 向上沟通 | 电梯汇报（L1，10 秒 / 30 秒）、坏消息汇报（L2，30/90）、争取资源（L2，30/90）、会上被质疑（L3，15/75） |
| 协作管理 | 跨部门推进（L2，30/90）、给出批评反馈（L3，30/90）、拒绝一个请求（L2，20/60） |
| 客户商务 | 客户投诉（L2，15/90）、45 秒价值陈述（L1，15/45）、议价谈判（L3，30/90）、向外行讲清行业（L1，20/90） |
| 求职呈现 | 面试行为题（L2，30/120）、面试行业题（L3，20/90）、场合化自我介绍（L1，15/40） |
| 即兴社交 | 临时被点名（L2，5/60）、即兴致辞（L1，15/60）、饭局上被问看法（L2，10/60） |
| 行业洞察 | 两分钟行业速评（L2，30/120）、趋势判断（L3，30/90） |

### 行业

餐饮连锁、电商零售、新能源汽车、医疗器械、银行与金融服务、企业软件（SaaS）、游戏、短视频与内容、物流快递、制造业、物业与地产、职业教育、酒店与旅游、农业与生鲜、咨询与专业服务、广告与品牌营销、消费电子与芯片、能源与光伏。

每个行业都有一份**行业画像**，包括：
- 你的岗位和上级；
- 协作部门、客户、采购方、供应商；
- 典型项目和坏消息；
- 3 个关键经营指标，例如餐饮的「翻台率」「食材成本率」「客单价」；
- 2 个行业变量和 2 个行业术语。

场景模板会把这些信息填进具体情境，所以同一类场景放在不同行业里，面对的对象、指标和矛盾都不一样。

### 认知补课

每张卡附带 3–4 个补课问题，例如：
- “这个行业的钱主要从哪里来？最大的一笔成本是什么？”
- “「翻台率」「食材成本率」分别怎么计算？什么水平算好？”
- “刚才哪一句你说得最含糊？把它查清楚。”

每张卡还附带检索关键词，例如“餐饮连锁 上市公司 年报 经营情况讨论与分析”。行业知识是在讲不出来之后再补的，这时学得最牢。

## 可观察检查清单

每类场景只考核 **4–5 项最关键的行为**，全部来自下面 20 项：

| 检查项 | 回听时判断的具体问题 |
| --- | --- |
| 结论先行 | 开口 15 秒内，对方已经知道你的结论、请求或立场 |
| 一条主线 | 全程围绕一条主线，没有临时岔开或越讲越散 |
| 具体可感 | 至少出现一个具体事实、数字、例子或画面 |
| 事实与推测分开 | 已确认的事实、你的判断和未知信息是分开说的 |
| 对方听得懂 | 用的是对方关心、听得懂的话，没有堆术语 |
| 下一步明确 | 结尾有明确的下一步：谁、做什么、什么时候 |
| 接住打断 | 被打断或追问时，先正面回应，再回到主线 |
| 按时收住 | 在规定时间内主动收尾，没有被时间截断 |
| 稳住节奏 | 卡壳、口头禅没有打断理解（明显卡顿不超过 3 次） |
| 先接情绪 | 先确认了对方的处境或情绪，再讲方案 |
| 讲出代价 | 说出了代价、风险或取舍，而不是只讲好处 |
| 承担责任 | 说清了自己的责任和动作，没有甩锅或泛泛而谈 |
| 从对方出发 | 从对方的目标或收益讲起，而不只讲自己的需要 |
| 把话轮交回 | 抛出一个具体问题，推动对方回应 |
| 故事有细节 | 讲的是一个具体瞬间：时间、场景和你的动作 |
| 层次可辨 | 听众能听出你讲了几点、正讲到第几点 |
| 不急于辩解 | 面对质疑先承认合理部分，没有急着反驳 |
| 有自己的判断 | 给出了明确的个人判断，而不是只罗列各方观点 |
| 给出替代 | 说“不”的同时，给出了一个可行的替代方案 |
| 不乱承诺 | 没有当场承诺自己控制不了的事 |

每一项都附带一句“下次怎么改”的具体说法，例如结论先行：“第一句话就给结论：‘结论是……，原因有两点。’”。选为重讲目标后，这句话会在补课和重讲时一直显示。

## 压力事件：打断与追问

共 18 种压力事件，每类场景配有适合它的打断池和追问池：

- **打断**：在首次表达的 40%–60% 处弹出。例如：
  - “说重点，你需要我做什么？”
  - “这个数字哪来的？你确定吗？”
  - “我只剩 20 秒了。”
  - “你们每次都这么说！”
- **追问**：在重讲开始前揭晓，重讲必须先回应它。例如：
  - “如果失败了，最坏的情况是什么？”
  - “只能给你一半，你怎么做？”
  - “能举一个具体例子吗？”

同一回合里，打断和追问不会重复。间隔复练时，会避开上次用过的打断和追问。

## 自适应选题

实践模式的首页轮盘约 5 秒定格到一张卡，选卡逻辑按以下顺序：

1. **到期复练**：完成 3–30 天、首轮有没做到的项、还没复练过的回合，有 50% 概率优先出现，并换一组压力事件。
2. **应用已学结构**：如果你在学习模式学过某些场景，约 70% 的回合会从这些场景里选，把学到的结构用到新行业上。
3. **弱项强化**：统计最近 20 个回合**首轮**（冷启动）的做到率；观察至少 3 次、且做到率最低（低于 70%）的一项就是弱项，优先选考核这一项的场景。
4. **场景交错**：不连续出同一家族、同一类场景。
5. **难度递进**：前 6 回合以 L1 为主，之后逐步纳入 L2、L3。针对弱项时放宽一级难度，避免反复出同一类场景。
6. **行业拓展**：在剩下的候选里，优先选近 30 天练得最少的行业。
7. **去重**：最近 30 个回合练过的卡不再出现。

也可以在首页把“场景范围”限定为某一类家族。

## 能力档案与训练历史

- **能力档案**
  - 每个检查项的首轮做到率（代表临场真实水平）和重讲做到率（代表改正能力），按首轮做到率从低到高排序；
  - “接住打断”的成功率、重讲改善率；
  - 18 个行业的覆盖情况和 6 类场景家族的分布。
- **训练历史**：每个回合的首次 → 重讲得分、重讲目标、遇到的打断和追问、补课关键词和带走的话，并标出复练回合和未完成回合。
- **首页概览**：今日回合数、近 7 天回合数、连续训练天数、行业覆盖、当前弱项和到期复练数量。

## 建议的练习节奏

以下是起步建议，不是研究结论：

- **刚开始**：每天学 1 课，学完马上用“去实践模式练这个场景”做一次闪电回合。先把 L1 的 6 课学完，再进入 L2。
- **学过一些结构后**：每天 1 个完整回合 + 1–2 个闪电回合，约 20 分钟；遇到练不好的场景，回学习模式重学这一课。
- **出现到期复练时**：优先完成。复练才能检验改进有没有留下来。
- **判断从严**：拿不准就算没做到。高估自己会让系统找不到你的真实弱项。
- **一次只改一项**：重讲时只盯住选定的目标，其他问题留到下一回合。

## 快速开始

**要求**

- Node.js 20.11 或更新版本
- Bun 1.3 或更新版本
- 支持 `MediaRecorder` 的现代浏览器（Chrome、Edge、Firefox、Safari 新版）

```bash
bun install
bun run dev
```

打开 `http://127.0.0.1:3000`。首次进入会显示一页简短说明，然后进入学习模式。

麦克风权限会在第一次开口时请求。拒绝后可以选择“只计时，不录音”，但回听检查只能凭记忆，准确度会下降。

**生产部署**

```bash
bun run build      # 校验离线缓存清单并生成 dist/
bun run start:prod # 以 NODE_ENV=production 提供 dist/
```

`public/_headers` 为静态托管平台提供与开发服务器一致的安全响应头。

## 配置

通过环境变量或 `.env` 配置（参考 `.env.example`）：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 监听地址 |
| `PORT` | `3000` | 监听端口，必须是 1–65535 的整数 |
| `STATIC_DIR` | 开发为 `public`，生产为 `dist` | 静态目录。只允许指向项目内、真实存在且包含 `index.html` 的目录，否则启动失败 |
| `NODE_ENV` | — | 设为 `production` 时默认提供 `dist/` |

## 技术实现要点

- **零前端依赖**：浏览器原生 ES Module 加字符串模板渲染，没有框架，也没有打包步骤。服务端只依赖 `express` 和 `dotenv`。
- **严格 CSP**：`style-src 'self'` 禁止内联样式属性，所有动态位移和宽度都通过 CSSOM 或 Web Animations API 写入。例如首页轮盘用 `element.animate()` 驱动，能力页的进度条用 `element.style.width` 写入。
- **状态机**：实战回合（`engine.js`）和课程（`lesson-engine.js`）都是纯函数，阶段顺序、校验、推进、选卡、统计都可以单独测试。界面层只负责渲染和计时。
- **计时不触发整页重渲染**：计时器每 200ms 直接更新时钟、进度条、打断提示和超时提示的 DOM 节点。阶段开始时间持久化，刷新后可以恢复倒计时。
- **录音健壮性**（`recorder.js`，两种模式共用）：
  - 等待麦克风授权期间进入“请求中”状态，可以随时改为只计时；
  - 授权迟到时自动释放麦克风；
  - 录音保存失败时按只计时处理，不中断回合。
- **存储**：
  - IndexedDB v2，包含 `kv`、`sessions`（主题训练）、`drills`（实战回合）、`recordings` 四个仓库；学习记录和当前课程保存在 `kv` 中。IndexedDB 不可用时退回到 localStorage。
  - 回合归档与当前进度在同一事务里写入。
  - 导入时按当前题库重新派生卡片元数据，拒绝未知题卡、未知检查项、跨场景的示范卡或迁移卡，以及重复记录。
- **离线与 PWA**：`sw.js` 预缓存完整模块图。`bun run build` 会校验 `app.js` 引用的每个本地模块都在缓存清单里，缺一个就构建失败。

## 测试

```bash
bun run test
```

当前共 58 项测试，覆盖：

- **学习模式**：
  - 19 课与 19 类场景一一对应，示范按顺序覆盖每一步，并且能在建议时长内讲完；
  - 课程按难度排序；一课完整走完时，提示会逐步撤掉，漏掉的步骤会被标出；
  - 迁移卡与示范卡行业不同，重学时迁移行业会轮换；
  - 实践模式约 70% 优先选已学场景；
  - 学习记录的存储校验与导入去重。
- **实战题库**：342 张卡完整生成，没有缺字段、未替换的模板或重复的补课问题；每类家族都有入门难度的场景。
- **回合引擎**：先开口后补课的阶段顺序；闪电回合跳过补课；打断落在中段且与追问不同；阶段校验与完成判定。
- **自适应选卡**：弱项按首轮统计且引导选卡、弱项强化时场景有多样性；家族交错、新行业优先；到期复练会换压力事件；家族筛选生效。
- **统计**：连续天数、行业覆盖、接住打断率、重讲改善率。
- **存储**：回合规范化、导出时剥离录音、导入校验与去重、事务原子性、数据库版本升级。
- **服务端与主题题库**：安全头、SPA 回退、`/health`、离线缓存版本、主题卡与年度计划。

## 隐私与数据

- 学习记录、训练记录、补课笔记、收藏和录音默认只保存在当前浏览器的 IndexedDB 中，不上传，也不接入广告或行为分析服务。
- 可以在“设置”中导出或导入 JSON。导出包含学习记录、实战回合和主题训练记录，但**不包含录音文件**；同一设备上再导入时，会保留本机已有的录音。
- “设置 → 清除本地数据”会删除全部数据库和本地缓存。
- 静态服务器仍可能处理提供页面所需的 IP、User-Agent 等基础访问信息，具体取决于部署环境。

## 内容边界与局限

- 行业画像只包含长期稳定的定性信息（岗位、常用指标名、典型矛盾），**不写具体数据**。行业事实需要你在补课阶段自行检索核实。
- 医疗器械、银行等场景只训练沟通方式，应用不提供诊断、法律意见或投资建议。
- 示范回答是按结构写出的一种好答案，**不是唯一正确的答案**。学的是结构和每一步的作用，不是逐字背诵。
- 回听判断仍由你本人完成，无法替代真人听众或教练的反馈。条件允许时，把录音给同事或朋友听，用同一份清单让他们判断。
- 打断和追问是文字提示，不是真人对话，模拟不了对方的语气和临场反应。
- 每天练几个回合最合适，目前没有直接针对口头表达训练的研究；上面的节奏只是起步建议。

## 研究依据

| 设计 | 证据 | 可信度 |
| --- | --- | --- |
| 新手先学示范（学习模式） | 示范例题效应元分析 g = 0.48（[Educational Psychology Review 2023](https://eric.ed.gov/?id=EJ1364058)，数学领域）；对新手有效的示范，对有经验者效果下降甚至变负，即专长逆转效应（[Kalyuga 等 2003](https://mrbartonmaths.com/resourcesnew/8.%20Research/Explicit%20Instruction/The%20Expertise%20Reversal%20Effect.pdf)） | 高（证据主要来自数学和理科，用到表达上是推论） |
| 提示逐步撤掉、最后迁移 | 从完整示范逐步过渡到独立完成，能提升近迁移表现（[Atkinson, Renkl & Merrill 2003](https://www.researchgate.net/publication/200772684_Transitioning_From_Studying_Examples_to_Solving_Problems_Effects_of_Self-Explanation_Prompts_and_Fading_Worked-Out_Steps)） | 中高 |
| 好坏示范对比 | 先分析对比案例再接受讲解，迁移表现更好（[Schwartz & Bransford 1998](http://aaalab.stanford.edu/assets/papers/earlier/A_time_for_telling.pdf)） | 中 |
| 先观察示范再练习 | 口头表达训练中，观察示范与练习结合时进步最大（[De Grez, Valcke & Roozen 2014](https://eric.ed.gov/?id=EJ1024484)）；观看示范视频能提升学生的演讲表现（[Okada 等 2017](https://www.researchgate.net/publication/322265508_R211_Okada_Sawaumi_Ito_T_2017_Effects_of_observing_model_video_presentations_on_Japanese_EFL_learners'_Oral_performance_Electronic_Journal_of_Foreign_Language_Teaching_14_129-144)） | 中 |
| 实践模式先开口、后补课 | 先尝试后学习优于先学后练：[Sinha & Kapur 2021](https://www.researchgate.net/publication/351889202_From_problem-solving_to_sensemaking_A_comparative_meta-analysis_of_preparatory_approaches_for_future_learning) 元分析，53 项研究，g = 0.36；[Richland, Kornell & Kao 2009](https://learninglab.uchicago.edu/Pre-Testing_files/RichlandKornellKao.pdf) 的预测试效应。前提是学习者已有一定基础，所以放在学习模式之后 | 高 |
| 二元可观察清单、从严判断 | 口头表达的自评普遍高于教师评分，相关约 r = 0.46（[De Grez 等 2012](https://eric.ed.gov/?id=EJ972240) 及同类研究）；要求使用结构化量表的录像自评，第二次表现更好（[Ritchie 2016](https://journals.sagepub.com/doi/10.1177/1469787416654807)） | 高 |
| 反馈聚焦任务行为、每次只改一项 | 反馈干预平均 d = 0.41，但超过三分之一反而降低表现；注意力越离开任务、越指向自我，效果越差（[Kluger & DeNisi 1996](https://www.mrbartonmaths.com/resourcesnew/8.%20Research/Marking%20and%20Feedback/The%20effects%20of%20feedback%20interventions.pdf)） | 高 |
| 中途打断与追问 | 带着焦虑练习的人，在压力下表现不下降（[Oudejans & Pijpers 2009](https://research.vu.nl/en/publications/training-with-anxiety-has-a-positive-effect-on-expert-perceptual--2/)）；压力接种训练元分析，压力下表现 r = 0.30（[Saunders 等 1996](https://www.researchgate.net/publication/13725612_The_effect_of_stress_inoculation_training_on_anxiety_and_performance)）。证据主要来自运动和职业领域，用到口头表达上是推论 | 中 |
| 间隔复练 | 间隔练习优于集中练习（[Cepeda 等 2006](https://augmentingcognition.com/assets/Cepeda2006.pdf)，839 项评估） | 高 |
| 场景交错 | 交错练习元分析 g = 0.42，效果随材料差异很大（[Brunmair & Richter 2019](https://www.psychologie.uni-wuerzburg.de/fileadmin/06020400/2019/Brunmair_Richter_in_press__2019_META-ANALYSIS_OF_INTERLEAVED_LEARNING.pdf)） | 中 |
| 向外行讲清行业 | 自我解释 g = 0.55（[Bisra 等 2018](https://gwern.net/doc/psychology/spaced-repetition/2018-bisra.pdf)）；为教而学 g ≈ 0.35–0.56（[Kobayashi 2019](https://onlinelibrary.wiley.com/doi/10.1111/jpr.12221)） | 中高 |
| 不迷信练习时长 | 刻意练习只解释约 12%–14% 的表现差异，在职业领域低于 1%（[Macnamara 等 2014](https://gwern.net/doc/psychology/2014-macnamara.pdf)）。所以本项目更看重**练习质量**：真实场景、压力、具体反馈，而不是累计时长 | 高 |
